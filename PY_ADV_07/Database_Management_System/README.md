# Employee Management System

## Project Description

This is a Python and PostgreSQL based Employee Management System.

The project connects Python with PostgreSQL using the Psycopg library and performs basic database operations.

## Technologies Used

- Python
- PostgreSQL
- Psycopg 3
- SQL
