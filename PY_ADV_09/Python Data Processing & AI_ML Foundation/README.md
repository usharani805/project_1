# Employee Data Analysis

## Project Overview

This project performs employee data analysis using Python and Pandas.

## Objective

The main objective is to clean employee data, analyze salary information, and generate useful insights from the dataset.

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Jupyter Notebook

## Dataset

The project uses an employee CSV dataset containing employee ID, name, department, and salary information.

## Data Processing

The following operations were performed:

* Loaded employee data from CSV
* Handled missing values
* Removed duplicate records
* Filtered and sorted data
* Calculated basic statistics
* Created cleaned employee data

## Analysis Results

* Total Salary: ₹217,500
* Average Salary: ₹54,375
* Median Salary: ₹53,750
* Highest Salary: Sita – ₹60,000
* Lowest Salary: Ravi – ₹50,000
* IT department has the highest number of employees

## Output Files

* `employee_analysis.py`
* `employees.csv`
* `cleaned_employees.csv`
* `Employee_Data_Analysis_Report.docx`

## Conclusion

The project successfully demonstrates employee data cleaning, processing, statistical analysis, and visualization using Python and Pandas.
