# Student Management System

## Project Description

This is a production-style Python application developed as part of the final practical assessment.

The application manages student information using Python and Object-Oriented Programming.

## Features

- Object-Oriented Programming
- Clean Project Structure
- Reusable Modules
- Input Validation
- Custom Exception Handling
- API Integration
- Logging
- Unit Testing
- Code Optimization
- Git Version Control
